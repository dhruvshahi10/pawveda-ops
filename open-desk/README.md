# Open Desk — render kit

The Open Desk is PawVeda's second content agent (project doc `claude/44-OPEN-DESK.md`). This folder is how it makes a
reel: one JSON spec in, one finished MP4 out, about a minute in a cloud session, no credits.

```
cd open-desk && npm install            # pinned: hyperframes 0.9.104, gsap 3.13.0
FACTORY=/path/to/pawveda-content-factory node build.mjs specs/<id>.json
```

Output: `../media/<id>/reel.mp4` (1080x1920, H.264, -14 LUFS, true peak under -1 dB, under 12 MB for jsDelivr) and
`.build/<id>/frame-0s.jpg`, `frame-1s.jpg`, `frame-3s.jpg`, `cover.jpg` for the gate.

## The spec

```json
{
  "id": "2026-11-29-open-grape",
  "series": "Can my dog eat this?",
  "plate": "brand/photo/2026-10-19-campaign-bank/food/grapes-table-dog.jpg",
  "focus": [55, 42],          // where the camera pushes in, % of the picture
  "panel": 760,               // height of the type panel; lower it to lift the animal out of the bottom UI zone
  "duration": 12.5,           // 14 s or less (F5), enforced
  "beats": [
    { "t": 0,   "ground": "cream", "headline": "Can my dog eat one grape?", "size": "hero" },
    { "t": 2.5, "ground": "cocoa", "badge": { "band": "neutral", "label": "The answer" }, "headline": "Give none.", "size": "hero" },
    { "t": 5.9, "ground": "cocoa", "body": "Grapes and raisins can hurt some dogs' kidneys, and no one knows a safe amount." },
    { "t": 9.2, "ground": "cream", "headline": "Ate some? Call your vet now.", "body": "Don't wait for signs." }
  ]
}
```

- Beat 0 has no eyebrow: the question is the first line on screen (F4), enforced.
- `ground: "cocoa"` is the answer (03: cream is the world, cocoa is the AI). Bands `danger`, `warn`, `ok` are triage
  colours only; anything else is `neutral` (terracotta).
- Put beat cuts off whole seconds (2.5, 5.9, 9.2) so the 3 s gate frame never lands on a blank cut.
- `footage` instead of `plate` uses a real clip (for example from the Drive inbox), muted under the sound bed.

## What it is made of

HyperFrames (Apache 2.0) renders the HTML; GSAP drives the camera push and the wipes (no fade-ups, no bounce: 03 §4, §7);
ffmpeg makes a procedural sound bed (a soft pad and a tick on each cut, no samples, nothing generated by AI) and the
final encode. Fonts are the brand's own OFL files (Lexend, Fraunces, JetBrains Mono), copied from the factory.

`specs/banked/` keeps specs that failed the gate twice. They are never queued.
